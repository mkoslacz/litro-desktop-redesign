## Architectural changes

- **Two link kinds, named.** `linkBase()` is gone. `pageBase()` is the origin the reviewer is on and
  serves every in-page navigation and history write; `shareBase()` is `prototypeUrl` and is
  reachable only through the new public `shareLink(thread)`. The old name was the defect: one
  function served two incompatible purposes and both callers took the wrong one. `prototypeUrl` was
  confined, not deleted.
- **`replaceState` is a convenience, not a precondition.** `openThread()` no longer treats writing
  the address bar as something that must succeed before the thread renders.
- **Review-page shell.** `proto-review.css` carries the shared look plus the shell markup as a
  copyable block in its header comment. No shared HTML partial and no fourth JS file were created —
  the prototype has no build step, so a partial would have needed a runtime include.

## Warnings
