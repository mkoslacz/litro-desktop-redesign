### The adversarial panel earned its place in round 1

Nine verifiers ran, three per card, each given a distinct lens and told to refute. On `IMPL-25` and
`IMPL-27` all six returned `refuted: false` after reproducing the implementer's measurements
themselves — one of them re-ran the new skill test in a scratch copy with an emptied store and
watched it go red, which is the only way to know an assertion can fail.

On `IMPL-26` **all three refuted, and both defects were real:**

1. **DoD bullet 3 broken.** The README text the card produced included
   `(created in Firebase Console → Project settings → Service accounts)` — a literal navigation path
   for obtaining the credential, which the DoD explicitly forbids ("states the requirement and
   stops"). Two independent lenses caught it. The implementer's own self-check had cited the very
   line containing the instruction as evidence it had not added one.
2. **False evidence.** The implementer reported `git status --porcelain shows only README.md
   modified`. It showed three files: the integrity gates had rewritten `changelog.json` and
   `usecases.built.json` and the claimed restore never happened.

The orchestrator fixed both and found a third the panel had not been pointed at: the text credited
the `createFirebaseClient` + `loadModule` seam to `tools/comments.js`. Both live in
`proto-comments.js`; `tools/comments.js` is the Admin SDK CLI. The section was rewritten and
re-measured before the commit.

## Architectural changes

- **A third panel sheet built from a static body.** `addStaticSheet()` reuses the row, toggle and
  beside-the-sheet page-link shell of `addContentSheet()` and skips the fetch-and-render path, so a
  page with no listable data still joins the review surface without a second mechanism.
- **The non-empty rule as a testable contract.** `SKILL.md` now states that a criterion over a
  queried set must assert the set is non-empty, and the skill suite pins the overview's real card
  class so selector drift is caught by a test rather than by a reader.
