## Architectural changes

- **The two-link rule promoted from comment to contract.** `pageBase()`/`deepLink()` for anything a
  reviewer clicks in-page, `shareBase()`/`shareLink()` only for a link meant to be pasted elsewhere.
  It now lives in `SKILL.md` PHASE 11 prose, in `CLAUDE.md`, and in the code — because it existing
  only in a code comment is the documented cause of `IV-01`.
- **Overview mode.** An init-time flag meaning "this page owns no anchors", short-circuiting
  `renderThreads()` before the pin/tray/orphan logic. It replaces a CSS workaround with a mechanism,
  and it is what makes `IMPL-17`'s guard unreachable from the overview at all.
- **Page identity as a whole normalised path.** `pagePath()` and `safePagePath()` make the render
  decision and the navigate decision agree; previously `belongsToThisPage` compared paths while
  `needsRestore` compared basenames.
- **One round label, two consumers.** `roundLabel()` serves the changelog heading and its jump nav,
  so the two cannot drift — the shape the card asked for after `unreleased` reached the page as an
  untranslated `<h2>`.

Two pairs share a root cause and were each fixed once: `IMPL-19`/`IMPL-20` are both "a rule at class
specificity deciding what an attribute or an element type should decide", and `IMPL-13`/`IMPL-17` are
both "the layer writing about a page it cannot establish anything about".

## Deviations from plan

1. **IMPL-23, orchestrator correction on integration.** The agent's guard used `!Number.isNaN(n)`;
   the card says the value must "parse as a finite number". `+'Infinity'` is a number and is not
   NaN, so `?rooms=Infinity` would have rendered as one. Changed to `Number.isFinite(n)` in both
   engines and re-measured: `?rooms=Infinity` now falls back to the default.
2. **IMPL-17, template half deliberately not ported.** The card is emphatic that the permissive
   return for a page-less thread is load-bearing and that only the *write* should be skipped. The
   parallel skill round resolved the same finding the opposite way — a page-less thread belongs to
   **no** page — and pinned that with a committed test and with `SKILL.md` prose. Porting this
   card's shape would have reverted their work and broken a test, both forbidden. Prototype and
   template therefore diverge on where a page-less legacy thread renders. **Operator arbitration
   needed.**
3. **IMPL-11, copy affordance not added to the template.** `template-contract.test.js` asserts the
   overview template contains **no** call to `shareLink(` at all. A copy-link button is exactly the
   legitimate non-in-page use of `shareLink`, but that regex cannot tell it from a row `href`.
   Adding it breaks a committed test; loosening the regex weakens one. The prototype has the
   affordance; the template does not. **Operator arbitration needed.**
4. **IMPL-14 edge case resolved against the card's own note.** The card says a thread whose
   `anchor.page` legitimately *is* `comments.html` must not be read as a mismatch. The parallel
   round pinned the opposite with a test, and its argument is the stronger one: since `IMPL-13` the
   overview draws no pins, so a link there opens nothing — the very link-to-nowhere `IMPL-14`
   exists to remove. Implemented the card's filename rule **and** the self-page guard, so prototype
   and template now agree and every DoD bullet still passes.
5. **IMPL-16, no new test added.** The colliding-direction coverage the card asks for had already
   been added by the parallel round in `6c3fe0a`. A duplicate would be churn. The bullet's "140 or
   higher" is satisfied at 161.
6. **IMPL-16 item 3 went beyond a check.** `safePageName`/`needsRestore` genuinely disagreed with
   the render decision, so it was fixed in both repositories rather than only reported.
